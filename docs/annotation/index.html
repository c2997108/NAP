解析方法
PortablePipelineのannotation~rRNA-for-metabarcodingをブラウザに移植しています。BLAST検索は既定のmegablast条件を使い、フィルター後のヒットからLCAを計算します。異なる分類の根が混在する場合は葉緑体候補を優先し、その共通祖先を使います。内部コントロールは分類を上書きします。
参照DBは分割を順次読み込み、全分割のヒットを合わせてから500参照配列の上限・フィルター・LCAを適用します。入力配列・品質・カウントは外部サービスへ送信しません。分類結果は使用する参照DBの内容に依存します。
